##  Features

-  Smooth spaceship movement
-  Multiple enemy types
-  Boss battles
-  Score & High Score
-  Retro sound effects
-  Health system

---

## 🎮 Controls

| Key | Action |
|------|--------|
| A / D or ← / → | Move |
| Space | Shoot |
